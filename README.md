# Personal Portfolio Website — Shrey Prakash

A clean, modern, and responsive personal portfolio website for **Shrey Prakash** (BCA student at Uttaranchal University). All data is hardcoded directly into the semantic markup, requiring **zero database configuration, zero external installations, and zero backend services**.

---

## 🌟 Highlights

- **Pure Static & Zero-Config**: Runs instantly by simply double-clicking `index.html` in any web browser, or hosting on GitHub Pages, Netlify, or Vercel.
- **Editorial Design & Typography**: Clean aesthetic with Fraunces serif headings, Inter body typography, and JetBrains Mono code tags.
- **Interactive Features**:
  - Interactive SVG data structure graph with mouse parallax in the hero header.
  - Client-side project tag filtering (`All`, `C++`, `Python`, `SQL`, `DSA`).
  - Sticky navigation with scroll-position observer (ScrollSpy).
  - Validated contact form with interactive feedback toasts and `mailto:` integration.
  - One-click resume download (`Shrey_Prakash_CV.pdf`).

## 🚀 How to View & Run

### Option 1: Direct File Opening (No tools needed)
Simply open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari).

---

### Option 2: Local HTTP Server (Optional)
If you wish to preview it via `localhost`:
```bash
python server.py
# or
python -m http.server 3000
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

---

## 🌐 Deploy in Seconds

- **GitHub Pages**: Go to repository *Settings* → *Pages* → select `main` branch root folder → *Save*.
- **Vercel**: Import the repository and click *Deploy* (auto-detects static HTML).
- **Netlify**: Drag and drop the `personal-portfolio` folder into [app.netlify.com/drop](https://app.netlify.com/drop).
